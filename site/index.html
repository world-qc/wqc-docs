World Quantum Computer

Protocol & API Reference

HTTP contracts for the two services a participant interacts with, plus the normative specifications that define what the payloads mean.

HTTP APIs

Orchestrator Client API port 9000

Submit circuits, poll task status and manifests, query fee quotes and balances, register an operator payout address, and discover libp2p bootstrap peers.

Core Engine API port 3000

The node-local simulation and proving engine. Node operators reach this on localhost; it is not exposed to the swarm.

Normative specifications

  • Circuit payload semantics — gate grammar, measurement rules, output modes, determinism, scale limits
  • Swarm P2P protocols — libp2p protocol IDs, framing, signature payload layouts
  • Current architecture — components and the task lifecycle as implemented
  • Economics — fees, rewards, and settlement
  • zk-STARK — proof system and verification

The API pages describe the structural contract — paths, status codes, and schemas. What the fields mean is normative in the specifications above. Where the two overlap, the specifications win.
